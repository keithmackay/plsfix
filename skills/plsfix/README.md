# plsfix

Rewrites vague specs/prompts/instructions/textfiles into clear, actionable ones.

Improves spec documents, prompts, requirements docs, briefs, and any written instructions meant to drive action from humans or AI. Diagnoses and rewrites the document against 12 research-backed writing principles, producing a rewritten version plus a change report that maps every edit to the principle it implements. Supports an optional `--ste` flag that also enforces ASD-STE100 (Simplified Technical English) language rules.
